Patches to upstream LineageOS projects
======================================

The device, vendor and kernel repositories carry their own changes. Changes
to LineageOS source projects live here, one directory per LineageOS release:

  los-16.0/   LineageOS 16.0 (Android 9), the current port.
              Apply with los-16.0/apply.sh after `repo sync`; see
              los-16.0/README.md for what each patch does.

  los-14.1/   LineageOS 14.1 (cm-14.1, Android 7.1), the earlier port,
              kept for reference. See los-14.1/README.md and
              los-14.1/PORTING.md.
